# ABSTRAK

**Judul:** Rancang Bangun Sistem Informasi Layanan Servis Kendaraan Berbasis Mobile dengan Integrasi Random Forest Regression untuk Prediksi Estimasi Biaya Servis pada 201 Auto Garage

---

## Abstrak Bahasa Indonesia

Perkembangan teknologi informasi telah mengubah cara pelanggan mengakses layanan servis kendaraan. Namun, ketidakpastian biaya servis seringkali menjadi kendala utama yang menyebabkan keraguan pelanggan dalam melakukan pemesanan layanan. Penelitian ini bertujuan untuk merancang dan membangun sistem informasi layanan servis kendaraan berbasis mobile yang dilengkapi dengan prediksi estimasi biaya servis menggunakan algoritma Random Forest Regression pada 201 Auto Garage.

Sistem ini dikembangkan menggunakan framework Flutter untuk aplikasi mobile dengan arsitektur client-server, Firebase sebagai backend untuk autentikasi dan penyimpanan data real-time, serta implementasi model Random Forest Regression untuk memprediksi estimasi biaya berdasarkan parameter input seperti jenis layanan, kondisi kendaraan, tahun produksi, dan riwayat servis sebelumnya. Metode pengembangan sistem menggunakan pendekatan Agile dengan model iteratif untuk memastikan fleksibilitas dan adaptabilitas terhadap kebutuhan pengguna.

Hasil pengujian menunjukkan bahwa sistem mampu memberikan prediksi estimasi biaya dengan tingkat akurasi yang tinggi, dengan nilai Mean Absolute Percentage Error (MAPE) sebesar X%, R-squared sebesar Y%, dan Root Mean Squared Error (RMSE) sebesar Rp Z. Sistem juga berhasil meningkatkan efisiensi proses booking dengan waktu pemesanan yang berkurang hingga X% dibandingkan dengan sistem manual. Fitur-fitur utama meliputi autentikasi multi-platform (email, Google, Facebook), manajemen kendaraan pelanggan, pelacakan status servis real-time, riwayat transaksi, notifikasi push, serta dashboard admin untuk pengelolaan booking dan layanan.

Pengujian usability menggunakan metode System Usability Scale (SUS) menunjukkan skor rata-rata sebesar X, yang mengindikasikan tingkat penerimaan pengguna yang baik. Sistem ini memberikan kontribusi signifikan dalam meningkatkan transparansi biaya, kepercayaan pelanggan, dan efisiensi operasional bengkel. Penelitian selanjutnya dapat mengeksplorasi integrasi dengan sistem IoT untuk monitoring kondisi kendaraan secara real-time dan penambahan algoritma machine learning lainnya untuk rekomendasi jadwal maintenance preventif.

**Kata Kunci:** Sistem Informasi Servis Kendaraan, Mobile Application, Random Forest Regression, Prediksi Biaya Servis, Flutter, Firebase, Machine Learning

## Abstract (English)

The development of information technology has transformed the way customers access vehicle service facilities. However, cost uncertainty often becomes a major obstacle that causes customer hesitation in booking services. This research aims to design and develop a mobile-based vehicle service information system equipped with service cost estimation prediction using the Random Forest Regression algorithm at 201 Auto Garage.

The system is developed using the Flutter framework for mobile applications with client-server architecture, Firebase as the backend for authentication and real-time data storage, and implementation of the Random Forest Regression model to predict cost estimates based on input parameters such as service type, vehicle condition, production year, and previous service history. The system development method uses an Agile approach with an iterative model to ensure flexibility and adaptability to user needs.

Test results show that the system is capable of providing cost estimation predictions with high accuracy, with Mean Absolute Percentage Error (MAPE) value of X%, R-squared of Y%, and Root Mean Squared Error (RMSE) of Rp Z. The system also successfully improves booking process efficiency with booking time reduced by up to X% compared to the manual system. Main features include multi-platform authentication (email, Google, Facebook), customer vehicle management, real-time service status tracking, transaction history, push notifications, and admin dashboard for managing bookings and services.

Usability testing using the System Usability Scale (SUS) method shows an average score of X, indicating a good level of user acceptance. This system provides significant contributions in improving cost transparency, customer trust, and workshop operational efficiency. Future research can explore integration with IoT systems for real-time vehicle condition monitoring and addition of other machine learning algorithms for preventive maintenance schedule recommendations.

**Keywords:** Vehicle Service Information System, Mobile Application, Random Forest Regression, Service Cost Prediction, Flutter, Firebase, Machine Learning
